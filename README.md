# Pumpkin — адаптивный учебный сайт

## Контрольная работа №3

Тема: «Адаптивная вёрстка и доступность многостраничного HTML/CSS-сайта».

## Описание

Проект представляет собой адаптивную версию многостраничного HTML/CSS-сайта учебного каталога декораций Pumpkin. КР №3 выполнена на основе проекта КР №1, без Bootstrap.

## Адаптивные решения

- создан отдельный репозиторий `kr3-responsive-shop`;
- основа проекта перенесена из КР №1;
- добавлен файл `css/responsive.css`;
- `responsive.css` подключён на всех страницах после `style.css`;
- на всех страницах присутствует `viewport`;
- применён подход Mobile First;
- добавлены медиазапросы `min-width`;
- адаптирована шапка и навигация: на мобильном меню в колонку, с 768px — в строку;
- sticky-шапка включена только с 768px;
- адаптирован hero-блок, заголовок сделан через `clamp()`;
- адаптирована сетка карточек: 1 → 2 → 3 → 4 колонки;
- адаптирована страница каталога и боковой фильтр;
- добавлены responsive images: `max-width: 100%`, `srcset`, `sizes`, `loading="lazy"`;
- для карточки товара использован `<picture>`;
- адаптирована форма заявки: на мобильном одна колонка, с 768px — пары «подпись — поле»;
- адаптирована таблица характеристик.

## Доступность

- добавлена ссылка пропуска к основному содержимому `skip-link`;
- у основного содержимого есть `id="main"`;
- активный пункт меню помечен `aria-current="page"`;
- добавлен видимый фокус `:focus-visible`;
- проверены `label` у полей формы;
- проверены `alt` у изображений;
- таблица имеет `caption`, `scope="col"` и `scope="row"`;
- выполнена проверка через Lighthouse Accessibility.

## Самостоятельная доработка

Реализовано карточное представление таблицы характеристик на мобильном экране: при ширине до 639px таблица отображается как набор карточек, а с 640px возвращается обычный табличный вид. Это улучшает читаемость страницы товара на телефоне и убирает необходимость горизонтальной прокрутки таблицы на мобильном.

## Аудит доступности (Lighthouse)

Для проверки доступности интерфейса был использован инструмент Lighthouse (категория Accessibility). 
Проверка проводилась в браузере на локальном сервере (localhost).

**Проверенные страницы:**
- `index.html`
- `catalog.html`
- `order.html`

**Найденные и исправленные проблемы:**
В ходе первичного аудита были выявлены проблемы с контрастностью текста и фона (Background and foreground colors do not have a sufficient contrast ratio):
1. Недостаточный контраст цены в карточках товаров со скидкой. Цвет текста был изменен на более светлый оттенок.
2. Недостаточный контраст текста на бейдже «Скидка». Цвет фона и текста был скорректирован для соответствия стандартам WCAG.

После внесения изменений в `css/style.css` итоговая оценка доступности (Accessibility) для проверенных страниц составила **100/100**.
